# Tuiter - Social Media Platform

Tuiter is a social media platform where users can register an account, login, see all the latest posts created by other users, search posts by ID and title. Users can create, read, update and remove posts, update their profiles and visit other users' profiles and posts.

Keep in mind that a Noroff student email address (@stud.noroff.no) is required to register.

# Built with

- HTML
- SCSS
- Bootstrap
- Javascript

# Features

- User registration and authentication
- Create, read, update, and delete posts
- Profile management
- Social interactions (following, reactions)
- Post search functionality
- Responsive design

# Getting Started

## Prerequisites

- Node.js (version 14 or higher)
- npm (comes with Node.js)
- Noroff student email address (@stud.noroff.no)

## Installation

1. Clone the repository:

```bash
git clone https://github.com/AB30001/js2-ca-arnb.git
```

2. Navigate to the project directory:

```bash
cd js2-ca-arnb
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

## Building for Production

To build the application for production:

```bash
npm run build
```

# Usage

1. Register an account using your Noroff student email (@stud.noroff.no)
2. Log in with your credentials
3. Browse posts from other users
4. Create, edit, or delete your own posts
5. Update your profile
6. Follow other users and interact with their content

# API Integration

This project uses the Noroff API for all backend functionality. A Noroff student email (@stud.noroff.no) is required for registration and authentication.
